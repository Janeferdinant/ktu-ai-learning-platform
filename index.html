Module 1 • Perceptron Weight Update Bloom: Level 3 (Apply) • 6 Marks
Numerical Problem 1: A single-layer perceptron has current weight vector w = [0.3, -0.4]ᵀ and bias b = 0.2 with learning rate η = 0.2. Input sample x = [1, 2]ᵀ is presented with target label y = +1. Using Rosenblatt's threshold activation f(z) = +1 if z ≥ 0 else -1, calculate the net input z, error e, and the updated weights w' and bias b'.
✓ Step-by-Step Numerical Working
Step 1: Compute Linear Net Input (z)
z = w₁x₁ + w₂x₂ + b = (0.3)(1) + (-0.4)(2) + 0.2 = 0.3 - 0.8 + 0.2 = -0.3
Step 2: Apply Threshold Activation Function
Since z = -0.3 < 0, the perceptron output is: ŷ = f(-0.3) = -1.

Step 3: Compute Classification Error (e)
e = y - ŷ = (+1) - (-1) = +2 (Misclassified)
Step 4: Compute Weight Updates (Δw and Δb)
Using Rosenblatt's rule: Δw = η · e · x and Δb = η · e
Δw₁ = (0.2)(+2)(1) = +0.4
Δw₂ = (0.2)(+2)(2) = +0.8
Δb = (0.2)(+2) = +0.4
Step 5: Compute Final Updated Weights and Bias
w₁' = w₁ + Δw₁ = 0.3 + 0.4 = +0.7
w₂' = w₂ + Δw₂ = -0.4 + 0.8 = +0.4
b' = b + Δb = 0.2 + 0.4 = +0.6
Verification: New net input z' = (0.7)(1) + (0.4)(2) + 0.6 = 0.7 + 0.8 + 0.6 = +2.1 ≥ 0, which correctly yields ŷ = +1.
Module 2 • Matrix Eigenvalues & Eigenvectors Bloom: Level 4 (Analyze) • 8 Marks
Numerical Problem 2: Given the matrix A = [[4, 2], [1, 3]], determine all eigenvalues λ₁ and λ₂, and find the corresponding normalized eigenvectors v₁ and v₂.
✓ Step-by-Step Numerical Working
Step 1: Set Up Characteristic Equation: det(A - λI) = 0
det([[4 - λ, 2], [1, 3 - λ]]) = (4 - λ)(3 - λ) - (2)(1) = 0
12 - 7λ + λ² - 2 = 0 => λ² - 7λ + 10 = 0
(λ - 5)(λ - 2) = 0 => λ₁ = 5, λ₂ = 2
Step 2: Find Eigenvector for λ₁ = 5
Solve (A - 5I)v = 0:
[[4 - 5, 2], [1, 3 - 5]] [[v₁], [v₂]] = [[-1, 2], [1, -2]] [[v₁], [v₂]] = [[0], [0]]
Equation: -v₁ + 2v₂ = 0 => v₁ = 2v₂
Let v₂ = 1 => v = [2, 1]ᵀ
Normalized: ||v|| = √(2² + 1²) = √5 => v̂₁ = [2/√5, 1/√5]ᵀ ≈ [0.894, 0.447]ᵀ
Step 3: Find Eigenvector for λ₂ = 2
Solve (A - 2I)v = 0:
[[4 - 2, 2], [1, 3 - 2]] [[v₁], [v₂]] = [[2, 2], [1, 1]] [[v₁], [v₂]] = [[0], [0]]
Equation: v₁ + v₂ = 0 => v₁ = -v₂
Let v₂ = 1 => v = [-1, 1]ᵀ
Normalized: ||v|| = √((-1)² + 1²) = √2 => v̂₂ = [-1/√2, 1/√2]ᵀ ≈ [-0.707, 0.707]ᵀ
Module 2 • Singular Value Decomposition (SVD) Bloom: Level 4 (Analyze) • 10 Marks
Numerical Problem 3: For the rectangular matrix X = [[3, 2, 2], [2, 3, -2]], calculate the non-zero singular values σ₁ and σ₂, and construct the singular value matrix Σ.
✓ Step-by-Step Numerical Working
Step 1: Compute the Gram Matrix XXᵀ (2×2)
XXᵀ = [[3, 2, 2], [2, 3, -2]] [[3, 2], [2, 3], [2, -2]]
(1,1) = 3² + 2² + 2² = 9 + 4 + 4 = 17
(1,2) = 3(2) + 2(3) + 2(-2) = 6 + 6 - 4 = 8
(2,1) = 8
(2,2) = 2² + 3² + (-2)² = 4 + 9 + 4 = 17
XXᵀ = [[17, 8], [8, 17]]
Step 2: Find Eigenvalues of XXᵀ
det([[17 - λ, 8], [8, 17 - λ]]) = (17 - λ)² - 64 = 0
(17 - λ) = ±8 => λ₁ = 17 + 8 = 25, λ₂ = 17 - 8 = 9
Step 3: Compute Singular Values (σᵢ = √λᵢ)
σ₁ = √25 = 5
σ₂ = √9 = 3
Step 4: Form the Singular Value Matrix Σ (2×3)
Σ = [[5, 0, 0], [0, 3, 0]]
Module 3 • Multi-Machine Defect Probability Bloom: Level 3 (Apply) • 8 Marks
Numerical Problem 4: A manufacturing facility uses 3 CNC machines M1, M2, and M3 producing 50%, 30%, and 20% of all parts respectively. Defective output rates are: P(Defect | M1) = 2%, P(Defect | M2) = 4%, and P(Defect | M3) = 5%. If a randomly selected part is found defective, find the probability that it was produced by Machine M2.
✓ Step-by-Step Numerical Working
Step 1: Identify Priors and Conditional Likelihoods
P(M1) = 0.50, P(Defect|M1) = 0.02
P(M2) = 0.30, P(Defect|M2) = 0.04
P(M3) = 0.20, P(Defect|M3) = 0.05

Step 2: Calculate Total Probability of a Defect (Evidence P(D))
P(D) = P(D|M1)P(M1) + P(D|M2)P(M2) + P(D|M3)P(M3)
= (0.02)(0.50) + (0.04)(0.30) + (0.05)(0.20)
= 0.010 + 0.012 + 0.010 = 0.032 (3.2%)
Step 3: Apply Bayes' Theorem for P(M2 | D)
P(M2|D) = [P(D|M2) · P(M2)] / P(D) = [0.04 × 0.30] / 0.032 = 0.012 / 0.032 = 0.375 (37.5%)
Conclusion: Although Machine M2 produces only 30% of total parts, given a defect, the probability it originated from M2 rises to 37.5% due to its elevated failure rate.
Module 4 • Ordinary Least Squares (OLS) Regression Bloom: Level 3 (Apply) • 8 Marks
Numerical Problem 5: For 4 cutting tool wear test samples, cutting speed x and wear rate y were recorded as: (1, 2), (2, 3), (3, 5), (4, 6). Calculate the OLS regression slope w₁, intercept w₀, and predict the tool wear rate at cutting speed x = 5.
✓ Step-by-Step Numerical Working
Step 1: Compute Means (x̄, ȳ)
x̄ = (1 + 2 + 3 + 4) / 4 = 10 / 4 = 2.5
ȳ = (2 + 3 + 5 + 6) / 4 = 16 / 4 = 4.0
Step 2: Construct Deviation Products Table
x_i: [1, 2, 3, 4] => (x_i - x̄): [-1.5, -0.5, +0.5, +1.5] => (x_i - x̄)²: [2.25, 0.25, 0.25, 2.25] => ∑(x_i - x̄)² = 5.0
y_i: [2, 3, 5, 6] => (y_i - ȳ): [-2.0, -1.0, +1.0, +2.0]
(x_i - x̄)(y_i - ȳ): [(-1.5)(-2)=3.0, (-0.5)(-1)=0.5, (0.5)(1)=0.5, (1.5)(2)=3.0] => ∑(x-x̄)(y-ȳ) = 7.0
Step 3: Calculate Slope w₁ and Intercept w₀
w₁ = ∑(x - x̄)(y - ȳ) / ∑(x - x̄)² = 7.0 / 5.0 = 1.4
w₀ = ȳ - w₁x̄ = 4.0 - (1.4)(2.5) = 4.0 - 3.5 = 0.5
Fitted Regression Line: ŷ = 1.4x + 0.5

Step 4: Predict Wear Rate at x = 5
ŷ(5) = 1.4(5) + 0.5 = 7.0 + 0.5 = 7.5 units
Module 4 • Confusion Matrix Evaluation Bloom: Level 3 (Apply) • 6 Marks
Numerical Problem 6: A predictive maintenance classifier evaluating 300 machine components produces the following confusion matrix: True Positives (TP) = 70, False Positives (FP) = 20, False Negatives (FN) = 10, True Negatives (TN) = 200. Calculate Accuracy, Precision, Recall, Specificity, and F1-Score.
✓ Step-by-Step Numerical Working
1. Accuracy = (TP + TN) / Total = (70 + 200) / 300 = 270 / 300 = 0.900 (90.0%)
2. Precision = TP / (TP + FP) = 70 / (70 + 20) = 70 / 90 = 0.778 (77.8%)
3. Recall = TP / (TP + FN) = 70 / (70 + 10) = 70 / 80 = 0.875 (87.5%)
4. Specificity= TN / (TN + FP) = 200 / (200 + 20) = 200 / 220 = 0.909 (90.9%)
5. F1-Score = 2 · (Precision · Recall) / (Precision + Recall)
= 2 · (0.7778 · 0.875) / (0.7778 + 0.875) = 1.3611 / 1.6528 = 0.823 (82.3%)

Algorithm 1: Rosenblatt's Perceptron Learning Algorithm (PLA)
Module 1 • Supervised Classification

Inputs: Training set D = {(xᵢ, yᵢ)} with xᵢ ∈ ℝᵈ, yᵢ ∈ {-1, +1}; Learning rate η > 0.
Output: Hyperplane weight vector w ∈ ℝᵈ and bias b ∈ ℝ satisfying yᵢ(wᵀxᵢ + b) > 0 for all i.

1. Initialize weight vector w = [0, 0, ..., 0]ᵀ and bias b = 0 2. Repeat until all training instances are correctly classified: 3. converged = True 4. For each sample (xᵢ, yᵢ) in D: 5. activation z = wᵀxᵢ + b 6. prediction ŷ = sign(z) // +1 if z ≥ 0, else -1 7. If ŷ ≠ yᵢ: 8. w = w + η · yᵢ · xᵢ // Update weights 9. b = b + η · yᵢ // Update bias 10. converged = False 11. If converged == True: Break and return (w, b)
Time Complexity: O(k · n · d), where k ≤ (R/γ)² updates
Space Complexity: O(d) for weight storage
Convergence Invariant: Guaranteed if linearly separable
Algorithm 2: Multi-Layer Perceptron (MLP) Backpropagation with Gradient Descent
Module 1 • Deep Learning

Inputs: Training samples {(xᵢ, yᵢ)}, L layers, activation function σ(z), loss function J.
Output: Optimized weights W⁽ˡ⁾ and biases b⁽ˡ⁾ minimizing loss J.

// FORWARD PROPAGATION PASS: 1. For layer l = 1 to L: 2. z⁽ˡ⁾ = W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ 3. a⁽ˡ⁾ = σ(z⁽ˡ⁾) // Activation (e.g. Sigmoid or ReLU) // BACKWARD PROPAGATION PASS (Error Deltas): 4. Output layer error: δ⁽ᴸ⁾ = ∇_{a} J ⊙ σ'(z⁽ᴸ⁾) 5. For hidden layer l = L-1 down to 1: 6. δ⁽ˡ⁾ = ((W⁽ˡ⁺¹⁾)ᵀ · δ⁽ˡ⁺¹⁾) ⊙ σ'(z⁽ˡ⁾) // GRADIENT DESCENT PARAMETER UPDATES: 7. For each layer l = 1 to L: 8. W⁽ˡ⁾ = W⁽ˡ⁾ - η · (δ⁽ˡ⁾ · (a⁽ˡ⁻¹⁾)ᵀ) 9. b⁽ˡ⁾ = b⁽ˡ⁾ - η · δ⁽ˡ⁾
Time Complexity: O(E · n · ∑ (n_{l} · n_{l-1}))
Space Complexity: O(∑ (n_{l} · n_{l-1})) for weights and activations
Core Principle: Multivariate Chain Rule of calculus
Algorithm 3: Principal Component Analysis (PCA) via Covariance Decomposition
Module 2 • Dimensionality Reduction

Inputs: Data matrix X ∈ ℝ^{n × d}, target reduced dimensions k (k < d).
Output: Lower-dimensional projected representation Z ∈ ℝ^{n × k} preserving maximal variance.

1. Compute feature column means: μ = (1/n) ∑_{i=1}ⁿ xᵢ 2. Center the data matrix: X̃ = X - 1 · μᵀ 3. Compute Covariance Matrix: Σ = (1/n) X̃ᵀ X̃ ∈ ℝ^{d × d} 4. Compute Eigenvalues λ and Eigenvectors v: solve det(Σ - λI) = 0 5. Sort eigenvalues in descending order: λ₁ ≥ λ₂ ≥ ... ≥ λ_d 6. Select top k eigenvectors to form projection matrix: V_k = [v₁, v₂, ..., v_k] ∈ ℝ^{d × k} 7. Project centered data onto k-dimensional subspace: Z = X̃ · V_k ∈ ℝ^{n × k}
Time Complexity: O(n · d² + d³) for covariance & eigendecomposition
Variance Retained: (∑_{j=1}ᵏ λⱼ) / (∑_{j=1}ᵈ λⱼ)
Alternative: SVD X̃ = U Σ Vᵀ avoids explicit X̃ᵀX̃
Algorithm 4: K-Means Clustering (Lloyd's Heuristic)
Module 4 • Unsupervised Clustering

Inputs: Dataset X = {x₁, ..., xₙ}, number of clusters K, convergence threshold ε.
Output: K cluster assignments C = {C₁, ..., C_K} and cluster centroid vectors {μ₁, ..., μ_K}.

1. Initialize K cluster centroids {μ₁, μ₂, ..., μ_K} randomly or via K-Means++ 2. Repeat until centroids change by less than ε: 3. // EXPECTATION STEP (Cluster Assignment): 4. For each data point xᵢ: 5. cᵢ = argmin_{k ∈ {1..K}} ||xᵢ - μ_k||² // Assign to nearest centroid 6. Assign xᵢ to cluster C_{cᵢ} 7. // MAXIMIZATION STEP (Centroid Update): 8. For each cluster k = 1 to K: 9. μ_k = (1 / |C_k|) ∑_{x ∈ C_k} x // Recompute centroid as mean 10. Return cluster assignments C and centroids μ
Time Complexity: O(t · K · n · d), where t is number of iterations
Space Complexity: O(n + K · d)
Objective: Minimizes within-cluster sum of squares (Inertia)

Question 1 • Module 1 3 Marks [1 Mark Theorem + 1 Mark Condition + 1 Mark Bound]
Q1. State the Perceptron Convergence Theorem. What is the fundamental geometric condition required for convergence?
✓ Official Scheme of Valuation & Answer Key
Answer:
1. Statement: If a training dataset is linearly separable by some hyperplane with margin γ > 0, the Rosenblatt Perceptron learning algorithm is guaranteed to converge to a separating hyperplane in a finite number of weight update steps. [1 Mark]
2. Geometric Condition: Linear separability — there must exist a weight vector w* such that yᵢ(w* · xᵢ) ≥ γ > 0 for all i. [1 Mark]
3. Convergence Bound: Maximum update steps k ≤ (R / γ)², where R = max ||xᵢ|| is the radius of the smallest sphere enclosing all samples. [1 Mark]
Question 2 • Module 1 3 Marks [1.5 Marks Role + 1.5 Marks Consequence]
Q2. Explain why non-linear activation functions are indispensable in multi-layer neural networks.
✓ Official Scheme of Valuation & Answer Key
Answer:
1. Linear Collapse: If all activation functions were linear f(z) = c·z, any composition of linear layers W₂(W₁x + b₁) + b₂ simply collapses mathematically to another single linear transformation W'x + b'. [1.5 Marks]
2. Non-Linear Capacity: Non-linear activations (e.g. ReLU, Sigmoid) allow the network to act as a Universal Function Approximator capable of learning arbitrary complex, non-linear decision frontiers (such as XOR). [1.5 Marks]
Question 3 • Module 2 3 Marks [1.5 Marks Symmetry + 1.5 Marks Positive Semi-Definite]
Q3. Prove that the sample covariance matrix Σ = (1/n) XᵀX is always symmetric and positive semi-definite.
✓ Official Scheme of Valuation & Answer Key
Answer:
1. Symmetry: Σᵀ = ((1/n) XᵀX)ᵀ = (1/n) Xᵀ (Xᵀ)ᵀ = (1/n) XᵀX = Σ. Therefore, Σ is symmetric. [1.5 Marks]
2. Positive Semi-Definite: For any arbitrary non-zero vector v ∈ ℝᵈ: vᵀ Σ v = vᵀ ((1/n) XᵀX) v = (1/n) (Xv)ᵀ (Xv) = (1/n) ||Xv||² ≥ 0. Since the norm squared is always non-negative, all eigenvalues of Σ must be λᵢ ≥ 0. [1.5 Marks]
Question 4 • Module 2 3 Marks [1 Mark Definition + 1 Mark SVD Relation + 1 Mark Applicability]
Q4. Differentiate between an Eigenvalue and a Singular Value.
✓ Official Scheme of Valuation & Answer Key
Answer:
1. Eigenvalues (λ): Satisfy Av = λv for square matrices A (n×n). They can be negative, zero, or complex. [1 Mark]
2. Singular Values (σ): Derived from rectangular matrices X (m×n). Defined as the positive square roots of the eigenvalues of XᵀX: σᵢ = √(λᵢ(XᵀX)). Always real and non-negative (σᵢ ≥ 0). [1 Mark]
3. Applicability: SVD exists for all rectangular matrices; Eigendecomposition requires square matrices. [1 Mark]
Question 5 • Module 3 3 Marks [1 Mark Formula + 1 Mark Components + 1 Mark Meaning]
Q5. State Bayes' Theorem and clearly define each component in the equation.
✓ Official Scheme of Valuation & Answer Key
Answer:
P(A | B) = [ P(B | A) · P(A) ] / P(B)
1. P(A | B): Posterior Probability — probability of hypothesis A after observing evidence B. [1 Mark]
2. P(B | A): Likelihood — probability of evidence B occurring given hypothesis A is true. [0.5 Mark]
3. P(A): Prior Probability — initial belief in hypothesis A before evidence is observed. [0.5 Mark]
4. P(B): Marginal Evidence — total probability of evidence B under all hypotheses. [1 Mark]
Question 6 • Module 3 3 Marks [1.5 Marks Statement + 1.5 Marks Application in ML]
Q6. State the Central Limit Theorem (CLT) and explain its importance in Machine Learning.

Q7. Compare L1 (Lasso) and L2 (Ridge) regularization in linear models.
✓ Official Scheme of Valuation & Answer Key
Answer:
1. L1 Regularization (Lasso): Adds penalty λ ∑ |wⱼ| to loss. Produces sparse weight vectors by driving unimportant weights exactly to zero, effectively performing automatic feature selection. [1.5 Marks]
2. L2 Regularization (Ridge): Adds penalty λ ∑ wⱼ² to loss. Shrinks all weights smoothly toward zero without eliminating them completely, mitigating multicollinearity. [1.5 Marks]

Q8. Why does the K-Means algorithm struggle with concentric or non-convex cluster shapes?
✓ Official Scheme of Valuation & Answer Key
Answer:
1. Spherical Voronoi Limitation: K-Means computes Euclidean distance to single point centroids ||x - μ_k||², implicitly assuming clusters are spherical and isotropic. Its decision boundaries are linear hyperplanes (Voronoi tessellation), which cannot separate nested concentric rings or crescent shapes. [1.5 Marks]
2. Remedy: Use density-based clustering (DBSCAN) or spectral clustering with non-linear kernels. [1.5 Marks]

Q9 (a). Derive the gradient descent weight update rule for a single neuron using Binary Cross-Entropy loss and Sigmoid activation: J(w) = - [ y ln(a) + (1-y) ln(1-a) ]. (5 Marks)
Q9 (b). Explain the vanishing gradient problem in deep neural networks and state how the ReLU activation mitigates it. (4 Marks)
✓ Official Scheme of Valuation & Answer Key (Q9)
Answer 9 (a): Derivation of Gradient [5 Marks]
Net input: z = wᵀx + b. Activation: a = σ(z) = 1 / (1 + e⁻ᶻ).
Derivative of Sigmoid: da/dz = a(1 - a). [1 Mark]
By chain rule: ∂J/∂wⱼ = (∂J/∂a) · (da/dz) · (∂z/∂wⱼ). [1 Mark]
∂J/∂a = - [ y/a - (1-y)/(1-a) ] = - [ y(1-a) - a(1-y) ] / [ a(1-a) ] = - (y - a) / [ a(1-a) ] = (a - y) / [ a(1-a) ]. [1.5 Marks]
Multiplying: ∂J/∂wⱼ = [ (a - y) / (a(1-a)) ] · [ a(1-a) ] · xⱼ = (a - y) · xⱼ. [1 Mark]
Weight update: wⱼ ← wⱼ - η (a - y) xⱼ. [0.5 Mark]

Answer 9 (b): Vanishing Gradient & ReLU [4 Marks]
For Sigmoid, maximum derivative σ'(z) = 0.25 (at z=0). During backpropagation through L layers, gradients multiply by at most 0.25ᴸ, decaying exponentially to near zero for early layers. [2 Marks]
ReLU defined as f(z) = max(0, z) has constant derivative f'(z) = 1 for all z > 0, preventing gradient attenuation regardless of network depth. [2 Marks]

Q11. Given the 2×2 data matrix X = [[3, 2], [2, 3]], compute its Singular Value Decomposition (SVD): X = U Σ Vᵀ. Verify that U and V are orthogonal matrices. (9 Marks)
✓ Official Scheme of Valuation & Answer Key (Q11)
Step 1: Compute XᵀX and its Eigenvalues [3 Marks]
Since X is symmetric (X = Xᵀ): XᵀX = X² = [[3, 2], [2, 3]] [[3, 2], [2, 3]] = [[13, 12], [12, 13]].
det(XᵀX - λI) = (13 - λ)² - 144 = 0 => 13 - λ = ±12 => λ₁ = 25, λ₂ = 1.
Singular values: σ₁ = √25 = 5, σ₂ = √1 = 1.
Σ = [[5, 0], [0, 1]].

Step 2: Compute Right Singular Vectors V (Eigenvectors of XᵀX) [3 Marks]
For λ₁ = 25: (13 - 25)v₁ + 12v₂ = 0 => -12v₁ + 12v₂ = 0 => v₁ = [1/√2, 1/√2]ᵀ.
For λ₂ = 1: (13 - 1)v₁ + 12v₂ = 0 => 12v₁ + 12v₂ = 0 => v₂ = [-1/√2, 1/√2]ᵀ.
V = [[1/√2, -1/√2], [1/√2, 1/√2]].

Step 3: Compute Left Singular Vectors U [2 Marks]
u₁ = (1/σ₁) X v₁ = (1/5) [[3, 2], [2, 3]] [1/√2, 1/√2]ᵀ = (1/5) [5/√2, 5/√2]ᵀ = [1/√2, 1/√2]ᵀ.
u₂ = (1/σ₂) X v₂ = (1/1) [[3, 2], [2, 3]] [-1/√2, 1/√2]ᵀ = [-1/√2, 1/√2]ᵀ.
U = [[1/√2, -1/√2], [1/√2, 1/√2]].

Step 4: Verify Orthogonality [1 Mark]
UᵀU = VᵀV = [[1/2 + 1/2, -1/2 + 1/2], [-1/2 + 1/2, 1/2 + 1/2]] = [[1, 0], [0, 1]] = I. Proved.
